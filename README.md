# Snake Water Gun Game

A simple Snake Water Gun game built with Python where the player competes against the computer. The player and computer choose Snake, Water, or Gun, and the program determines the winner based on the game rules.

## How It Works

The player chooses one of three options:

- Snake
- Water
- Gun

The computer randomly selects one of the three options.

The winner is determined using these rules:

- Snake beats Water
- Water beats Gun
- Gun beats Snake
- If both choose the same option, it is a draw

## Features

- Player vs. computer gameplay
- Random computer choices
- Automatic winner detection
- Draw detection
- Simple command-line interface
- Interactive user input
